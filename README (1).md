# YuvaIntern Week 4 - Machine Learning Model Development and Evaluation

## Project
Machine Learning Model Development and Evaluation using Logistic Regression.

## Dataset
Public Iris dataset: 150 observations, 4 numerical features, 3 species.

## Pipeline
1. Load and inspect data
2. Separate features and target
3. Stratified 80/20 train-test split
4. Standardize features using StandardScaler
5. Train Logistic Regression
6. Evaluate using accuracy, precision, recall, F1-score, confusion matrix and ROC curves

## Results
Training accuracy: 0.958
Test accuracy: 0.933
Precision: 0.933
Recall: 0.933
F1-score: 0.933
Test error rate: 0.067
